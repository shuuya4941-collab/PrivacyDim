# Privacy Dim — تطبيق تعتيم الشاشة التلقائي

## ماذا يفعل التطبيق
1. **تعتيم عند فتح تطبيق معيّن**: عبر خدمة إمكانية وصول (Accessibility Service) تراقب اسم حزمة التطبيق النشط حاليًا فقط (لا تقرأ أي محتوى نصي على الشاشة).
2. **تعتيم عند غياب الوجه**: عبر الكاميرا الأمامية + مكتبة ML Kit للتعرف على الوجوه؛ إذا لم يُكتشف وجه لمدة تتجاوز المهلة المحددة (افتراضيًا 3 ثوانٍ) تُفعَّل طبقة التعتيم.
3. **زر Quick Settings Tile**: يعمل مع لوحة تحكم سامسونج One UI لأنها مبنية فوق نفس واجهة `TileService` القياسية في أندرويد — يفعّل/يوقف النظام بالكامل بضغطة واحدة.
4. طبقة التعتيم شفافة وغير قابلة للمس (`FLAG_NOT_TOUCHABLE`)، أي أنها تعتّم بصريًا فقط دون منع استخدام الهاتف.

## خطوات التشغيل
1. افتح المجلد في Android Studio (Hedgehog أو أحدث) واتركه يزامن Gradle.
2. شغّل التطبيق على جهاز حقيقي (الكاميرا لا تعمل جيدًا على المحاكي غالبًا).
3. من الشاشة الرئيسية:
   - اضغط **"منح صلاحية العرض فوق التطبيقات"** وفعّلها من الإعدادات.
   - اضغط **"تفعيل خدمة إمكانية الوصول"** وفعّل "Privacy Dim" من القائمة.
   - أدخل اسم حزمة التطبيق المستهدف (مثال: `com.whatsapp`، `com.instagram.android`).
   - فعّل السويتشات المطلوبة واحفظ.
4. لإضافة الزر إلى لوحة الإشعارات في سامسونج:
   - افتح لوحة الإشعارات → اسحب لأسفل بإصبعين → اضغط **"تعديل"** (Edit / زر القلم).
   - ابحث عن **Privacy Dim** واسحبه إلى اللوحة.
   - اضغط عليه لتفعيل/إيقاف النظام بالكامل.

## ملاحظات مهمة
- صلاحيات الكاميرا و"العرض فوق التطبيقات الأخرى" و"إمكانية الوصول" **لا يمكن منحها برمجيًا** — أندرويد يفرض موافقة يدوية صريحة من المستخدم لأسباب أمنية، وهذا التطبيق يوجّهك لصفحات الإعدادات الصحيحة فقط.
- خدمة كشف الوجه هي "Foreground Service" وستظهر إشعارًا دائمًا بحكم قوانين أندرويد الخاصة بالخصوصية (لا يمكن إخفاء استخدام الكاميرا في الخلفية عن المستخدم).
- استهلاك البطارية سيزداد عند تفعيل كشف الوجه لأنه يبقي الكاميرا الأمامية نشطة باستمرار.
- بإمكانك تعديل شدة التعتيم ومهلة غياب الوجه عبر `Prefs.setDimAlphaPercent()` و`Prefs.setFaceTimeoutMs()`، ويمكن ربطهما لاحقًا بـ SeekBar في الواجهة.
